# 控制台 v3 · 设计计划（frontend-design skill 流程：计划 → 对照 brief 自检 → 实现 → 自评）

> 方法来源：Anthropic 官方 `frontend-design` skill（github.com/anthropics/skills，2026-09-03 改版版）
> 视觉基调来源：用户桌面《教育教学Agent-微交互与动效设计-v0.1》**基调 B 冷白极简**
> 目标文件：`src\dist\panel\index.html`（单文件、无构建、零外链）

## 1. Design Thinking（写代码前先定四件事）

| 维度 | 结论 |
|---|---|
| **Purpose** | 控制台的主任务是：**3 秒内让人知道「现在是什么任务 / 到哪了 / 下一步是什么 / 需要我做什么」**。服务对象是长时间盯屏的开发者。 |
| **Tone** | **冷白极简**（用户指定"纯白色"）：纯白画布、无衬线、大留白、弱边框、几乎无阴影，克制到只剩一个记忆点。**明确拒绝**：渐变、玻璃拟态、发光、彩色卡片墙、AI 味紫色、深色默认。 |
| **Constraints** | 单 HTML 文件；不引外部字体/图片/JS（离线可用、零外链）；Windows Electron；信息密度要比 0.1.0 更紧（用户嫌"太空"）；动效遵守用户《微交互 v0.1》三档纪律；`prefers-reduced-motion` 必须降级且**不丢信息**。 |
| **Differentiation** | **唯一记忆点：焦点卡的进度环 + 左侧 2px 任务脉冲线。** 全站只有这两处会动，其余一律安静。 |

## 2. Token 系统

**Color（4–6 命名色 + 状态色）**

| Token | 值 | 用途 |
|---|---|---|
| `--canvas` | `#FFFFFF` | 纯白画布（默认） |
| `--surface` | `#FAFAFB` | hover / 分区底 |
| `--surface-2` | `#F3F3F5` | 选中态 / 表头底 |
| `--line` | `#E8E8EA` | 弱边框（卡片、输入框） |
| `--line-2` | `#F0F0F2` | 发丝分隔线 |
| `--ink` | `#16161A` | 主文本、主按钮 |
| `--ink-2` | `#5A5A62` | 次文本 |
| `--ink-3` | `#91919A` | 弱文本 / 占位 |
| `--accent` | `#1F6FEB` | 唯一强调色：进行中 / 焦点 |
| `--ok` `--warn` `--danger` | `#0F7B4E` `#A4600B` `#B42318` | 状态语义 |

**Type**：`system-ui, "Segoe UI", "Microsoft YaHei", "PingFang SC", sans-serif`（无 Inter/Roboto/Arial）。
19 / 15 / 13.5 / 12.5 / 11.5 五档；行高 1.55；正文行宽 < 80 字符；数字用 `tabular-nums`（不用等宽字体当标签）。
**禁止**：全大写标签、标题里只强调一个词、每个元素都套圆角卡片、渐变装饰。

**Radius**：6 / 10 / 14（冷白极简用小圆角）。
**Shadow**：只有浮层（抽屉 / Toast / 帮助框）保留 `0 6px 24px -14px rgba(22,22,26,.28)`；其余一律用 1px 边框表达层级。

**Layout**
```
┌──────────┬────────────────────────────────────────────┐
│ 侧栏 208 │ 顶栏 56（标题 + 副标题 │ 全局搜索 │ 图标钮）  │  纯白 + 底部 1px 线
│ 品牌/导航 ├────────────────────────────────────────────┤
│ 连接状态 │ 内容列 max-width 1120，左对齐                │
│ 快捷键   │ 焦点卡（脉冲线 + 进度环 + 正在做/下一步）     │
└──────────┴────────────────────────────────────────────┘
```
看板页为「焦点卡 → 统计条 → 左任务清单 / 右侧栏（队伍·预占·动态）」。

## 3. 动效纪律（直接引用用户《微交互与动效设计 v0.1》）

| Token | 值 | 用途 |
|---|---|---|
| `--t-micro` | 120ms | hover / 按压 / 选中 |
| `--t-base` | 200ms | 面板进出 / Toast / 卡片入场 |
| `--t-slow` | 600ms | 大范围布局变化 |
| `--t-draw` | 800ms | 描边类（进度环） |
| `--ease-snappy` | `cubic-bezier(.2,.9,.2,1)` | 按压、chips |
| `--ease-default` | `cubic-bezier(.22,.9,.28,1)` | 面板进出、卡片 |
| `--ease-soft` | `cubic-bezier(.25,.8,.35,1)` | Toast |

- 按压 `scale .97` + snappy；disabled 不播按压反馈。
- 数字变化**不加弹跳**：520ms ease-out 单向插值（已有 countUp 保持不变）。
- 进度环 `stroke-dashoffset` 600ms ease-out 单向增长，不来回摆。
- 「正在做」用 6px **呼吸点**（1.6s 透明度呼吸），仅在有任务进行中时渲染——状态可见，不是装饰。
- Toast：滑入 12px + 淡入 200ms，3.2s 自动退场。
- 同一屏同时动画元素 ≤ 4；列表只给首屏可见项入场。
- **不采纳**：光斑、渐变流动、波纹、粒子、装饰性 glow。
- `prefers-reduced-motion: reduce` → 动效时长归零，但**静态度仍表达同一信息**（数字直接到目标值、呼吸点变实心点）。

## 4. 对照 brief 的自检（skill 要求：写代码前先挑毛病）

| 初稿里的"AI 默认做法" | 判定 | 改法 |
|---|---|---|
| 深色为默认 + 分层深色背景 | ✗ 违背 brief（用户要纯白） | 默认纯白；深色降为可选且同样无渐变 |
| `.focus::after` 径向光晕 | ✗ 装饰性 glow（用户红线明令不采纳） | 删除 |
| 进度环 linearGradient 双色 | ✗ 渐变装饰 | 单色 `--accent` |
| 11 处 gradient / 3 处 blur / 32 处阴影 | ✗ 玻璃拟态套模板 | 全部删除，改 1px 边框 + 单一浮层阴影 |
| 卡片一律圆角 + 统一柔影 | ✗ "SaaS-card kit" | 阴影归零，靠边框与底色分层 |
| 每张卡片 hover 抬升 | ✗ 散落微交互 | 只保留边框变深 + 背景微变 |
| 大留白导致"太空" | ✗ 用户明确嫌空 | 收紧间距（卡片 16px、栅格 gap 10px、行高 1.55），信息密度上调 |
| 全部元素入场动画 | ✗ 同屏动画超 4 个 | 只保留焦点卡一次入场 + 首屏 3–5 项 |

**结论**：设计从「深色玻璃拟态 SaaS」整体切换为「纯白冷白极简」，唯一记忆点收敛到进度环 + 脉冲线。

## 5. 实现后的自评（Chanel 原则：出门前照镜子，摘掉一件配饰）

- 摘掉的配饰：**顶栏图标按钮的独立边框**（统一为无边框 ghost，hover 才出现边界），避免顶栏出现一排"小方块"。
- 摘掉的配饰：**焦点卡的右侧动态栏与左侧任务清单的等权重边框**（右栏改为发丝分隔的轻区块），把注意力交还给焦点卡。
- 保留：进度环（唯一强动效）、脉冲线（唯一状态色）、呼吸点（唯一循环动画）。
- 未做（刻意）：暗色模式仍保留为可选（那是 0.1.0 就有的用户功能，不删），但同样按冷白极简重做，不是渐变玻璃。
