六本豆 Lite 0.3.3 · 离线授权版

安装版：双击 EXE 安装包，按提示安装；安装完成后打开“六本豆 Lite”。
便携目录：双击 LiubendouLite.exe 或 启动.cmd。
需要 Windows 10/11 x64、.NET Framework 4.8 和 Microsoft Edge WebView2 运行时。
Node.js 运行时已经内置，无需另装 Node、Python 或浏览器。

首次授权
1. 首次启动显示“离线授权”窗口。
2. 填写姓名或备注（选填），点击“复制授权申请”，把申请码发给管理员。
3. 管理员在“lite六本豆授权工具.exe”点击“粘贴申请码”，选择期限，点击“签发并复制激活码”。
4. 复制管理员发来的激活码，点击“粘贴并激活”，成功后进入工作台。
5. 永久或限期授权都在本机验证，无需连接授权服务器。

授权绑定这台电脑及 Windows 账户。请保留本机数据目录，重装系统、删除身份资料或更换账户后可能需要重新申请。
续期：管理员从“签发记录 / 续期”载入对应设备、选择期限并重新签发；用户在工作台左下角或托盘“离线授权与续期”粘贴新激活码后退出并重新打开。
兼容旧方式：仍可导出 .lbdreq 申请文件、另存 .lic 许可证并导入。激活码为一段较长文本，请整段复制。

云端 Agent 接入
授权完成后，在“接入与提示词”使用管理员提供的一次性云端连接邀请码激活。
这是云端 Agent 访问本机所用的网络连接，与本机离线授权分别处理。
创建自己的任务和工作区，点击“复制给 Agent”，把授权地址、curl 流程和当前任务交接发给 Agent。
每台电脑使用各自设备身份和连接地址。每个任务独立保存记忆、概况和活动。
工作区是默认起点。可以直接要求 Agent 将文件保存到桌面或操作其他目录，无需修改工作区。
操作范围以你当前的明确指令为准；已授权的操作无需重复确认。实际操作受本机账户权限约束。
复制的连接提示词已加入 Python urllib 拦截提醒，请 Agent 使用 curl。

数据位置
%LOCALAPPDATA%\LiubendouLite\data
长期记忆、任务记录、设备身份和许可证保存在这里。卸载程序会保留此目录，便于重新安装和恢复。
关闭窗口会缩到托盘；退出并停止本机服务请使用托盘菜单或 停止.cmd。

软件保护
自己的后端及工具模块使用 AES-256-GCM 加密，原生授权入口经 Obfuscar 混淆。
签名验证、到期检查和设备密钥解封装在本地完成；私钥不随分发包提供。
这是对代码和授权的保护，不保证任何离线软件绝对无法被逆向或修改。
