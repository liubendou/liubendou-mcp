六本豆 Lite 0.2 · Windows 桌面版

1. 解压后双击 LiubendouLite.exe，不需要安装 Node.js 或 npm。
2. 进入「接入与提示词」，粘贴管理员发给你的邀请码，激活自己的电脑。
3. 新建任务并选择项目文件夹，每个任务分别保存记忆和概况。
4. 点击「复制给 Agent」，把整段授权连接提示词发给云端 Agent。
5. 云端 Agent 按提示词中的 curl 流程连接，工具会在你自己的电脑上执行。

每个邀请码只能使用一次，有效期 24 小时。每台电脑、每个任务都有独立连接。
管理员的「生成分享邀请码」按钮只在管理员客户端显示。

关闭窗口后程序会留在托盘，云端连接继续运行。
右键托盘选择「退出并停止服务」或双击「停止.cmd」才会退出。
电脑关机、休眠、退出程序或断网期间，云端无法操作；恢复后客户端会自动重连。

data 文件夹保存本机身份、任务、记忆和概况。更新程序时保留它；不要发给其他人。
分享给其他用户时请发送原始分发包，并单独给每个人生成邀请码。

系统要求：Windows 10/11 x64、.NET Framework 4.8、Microsoft Edge WebView2 Runtime。
分发包自带 Node.js 运行时；不包含你的 SSH 私钥、设备身份或管理员凭据。

当前版本经过隔离多客户端验证及服务器经公网调用验证；未做多台物理电脑和长期高并发测试。
